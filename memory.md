# Memory — durable facts

Durable, sourced facts. **Every claim carries a `Source:` line.**
No source, no claim — write `[source needed]` and let weekly review
chase it. Detail lives in `notes/`; this file holds only the facts
the brain must not forget or re-derive.

This is a **template**. It ships with placeholder examples only —
replace them with your own facts, or delete the sections you do
not need. Do not put secrets, credentials, health detail, or
work-confidential material here.
