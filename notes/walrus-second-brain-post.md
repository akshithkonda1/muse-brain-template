# Walrus second-brain post

> EXAMPLE NOTE — everything here is from a public post, not personal
> data. Kept as a worked example of an atomic note: one idea, one
> source, one conclusion.

- Idea: a plain folder of Markdown files plus a short map file becomes
  a living second brain when the agent loads the map every session.
- Source: Walrus (@Walrus_systems), X post, Nov 7, 2026.
  https://x.com/walrus_systems/status/2119163389897322712
- What the graph showed: the map loaded (under 200 lines);
  `rules/people.md` matched only on match; `skills/weekly-review`
  run; `memory.md` saved with a source under every claim;
  a writing rule flagged as conflicting with the map's naming rule,
  fix proposed. 3,211 → 3,365 records, 11,500+ links, one topic per
  file. No Obsidian, no database.
- Conclusion: the map + scan is the mechanism; the files are the
  brain. This template is built on exactly that pattern — see
  `wiki/second-brain-pattern.md` and [[example-project]].
