# wiki/ — the compiled wiki

Muse-owned. Summaries, entity pages, concept pages, synthesis —
built from `raw/` and kept current on every ingest. You
read it; Muse writes it.

## wiki/ vs notes/

- `notes/` — the atomic layer: one topic per file, written
  tight, with `Tags:` and `[[links]]`. This is where most of the
  brain lives (example notes included — replace them with your own).
- `wiki/` — the compiled layer: synthesis across many sources and
  notes. A wiki page answers a question that no single note answers
  (e.g. the pattern this whole brain is built on). Grows slowly, one
  page per real synthesis — not one per note.

Do not duplicate a note into `wiki/` under a new name. If a wiki
page and a note say the same thing, the wiki page links to the note.
