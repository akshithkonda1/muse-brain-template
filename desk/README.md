# desk/ — working surface

Drafts, in-progress thinking, half-formed comparisons — the stuff
that is not a note yet and may never be. Nothing here is load-bearing:
if a desk file is still here in a month, either file it (ingest) or
delete it (weekly review decides).

Conventions: dated names (`desk/2026-11-08-<slug>.md`), no `Tags:`
line required, link out to notes freely. The weekly review sweeps
this folder first.
